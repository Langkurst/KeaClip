# Security

If you find a security problem in KeaClip, please email keaclip@proton.me instead of opening a public issue. Say what you found and how to reproduce it; you'll get a reply, and a fix will go out as an update.

Every KeaClip download is listed with its SHA-256 in `SHA256SUMS.txt` on the release page, and the app checks updates against those values before installing them.
