# Contributing

Bug reports and ideas are welcome: use **Feedback** in the app, open an issue, or email keaclip@proton.me.

Code changes are welcome too. KeaClip is a small, focused app, so please open an issue first for anything big. To build and test, see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md); `./build/verify.ps1` runs everything. Contributions are accepted under the project's licence, GPL-3.0-or-later.
