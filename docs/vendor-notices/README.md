# Collected third-party notices

Full licence/copyright/notice texts copied from the exact restored packages and pinned upstream revisions on 2026-10-07. Package folders retain their original names and version metadata. `notice-hashes.json` records copied bytes; `upstream-provenance.json` records primary-source collection, including unavailable candidates. The exact standalone yt-dlp embedded notice is retained separately from its source notice.

These materials are bundled with the private preview. They are a concrete improvement over licence links alone and **do not complete redistribution clearance**. Matching sources, native plugin/contribution terms and build inputs remain incomplete; see `docs/research/REDISTRIBUTION.md` in the source repository. Do not give this preview to a friend until those obligations and the application's own licence are resolved. No replacement/debugging restriction is imposed on the third-party libraries by this notice.
